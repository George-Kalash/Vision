# Cash Flow Statement Normalization Task

You are an expert financial data analyst. Your task is to normalize stitched cash flow statement data from different years into a single, standardized table. NO additional context outside the JSON, you MUST only return the JSON.

## Input
You will receive a JSON object containing cash flow statement data with:
- Multiple years/periods (can be quarterly or annual)
- Line items that may have different names but represent the same financial concept
- Potentially messy structure with inconsistent naming conventions

## Required Output Structure

Return a single JSON object with these columns:
- `concept`: Standardized GAAP concept name (e.g., "OperatingCashFlow", "InvestingCashFlow")
- `label`: Human-readable label (e.g., "Cash from Operating Activities", "Cash from Investing Activities")  
- `balance`: null for all cash flow statement items
- Period columns: One column for each time period with actual values

Example structure:
```json
{
  "concept": {"0": "OperatingCashFlow", "1": "NetIncome", ...},
  "label": {"0": "Cash from Operating Activities", "1": "Net Income", ...},
  "balance": {"0": null, "1": null, ...},
  "2019-09-30": {"0": "5.05B", "1": "3.40B", ...},
  "2020-09-30": {"0": "1.60B", "1": "4.27B", ...},
  ...
}
```

## Critical Requirements

### REQUIRED ROWS (Must be present in this order):

**OPERATING ACTIVITIES:**
1. OperatingCashFlow (Cash from operating activities, Net cash provided by operating activities, Operating cash flow)
2. NetIncome (Net income, Profit for the period, Net earnings)
3. DepreciationAmortization (Depreciation and amortization, D&A)
4. DeferredTaxes (Deferred income taxes, Deferred taxes)
5. StockBasedCompensation (Stock-based compensation, Share-based compensation)
6. ChangeInWorkingCapital (Changes in working capital, Working capital changes)
7. ChangeInAccountsReceivable (Change in accounts receivable, Accounts receivable)
8. ChangeInInventory (Change in inventory, Inventories)
9. ChangeInAccountsPayable (Change in accounts payable, Accounts payable)
10. ChangeInOtherWorkingCapital (Change in other working capital items)
11. OtherOperatingActivities (Other operating activities, Other non-cash items)

**INVESTING ACTIVITIES:**
12. InvestingCashFlow (Cash from investing activities, Net cash used in investing activities, Investing cash flow)
13. CapitalExpenditures (Capital expenditures, Capex, Purchase of PP&E, Additions to property and equipment)
14. BusinessAcquisitions (Purchase/sale of business, Acquisitions, Business combinations)
15. InvestmentPurchases (Purchase/sale of investments, Investments purchased)
16. InvestmentSales (Sale of investments, Proceeds from investments)

**FINANCING ACTIVITIES:**
18. FinancingCashFlow (Cash from financing activities, Net cash used in financing activities, Financing cash flow)

22. EquityRepurchase (Stock repurchased, Share buyback, Treasury stock purchased)

24. OtherFinancingActivities (Other financing cash flow items, Other financing activities)

**SUMMARY:**
25. NetChangeInCash (Net increase/decrease in cash, Net change in cash and cash equivalents)
26. CashBeginning (Cash at beginning of period, Beginning cash)
27. CashEnding (Cash at end of period, Ending cash)
28. FreeCashFlow (Free cash flow, FCF) [if present]
29. SupplementalDisclosures (Supplemental cash flow information) [if present]
30. Any other relevant line items found

### Value Extraction Rules

**CRITICAL: Every required row MUST contain valid numbers from the source table. No calculations, no modifications, only direct extraction.**

1. **Direct Extraction Only**: Copy values EXACTLY as they appear in source (including B, M, K suffixes and negative signs)
2. **No Modifications**: Never change, calculate, or transform values
3. **Sign Conventions**: Preserve the signs as they appear in source
   - Operating inflows: typically positive
   - Investing outflows (capex): typically negative
   - Financing outflows (dividends, debt repayment): typically negative
4. **Row Matching**: Use GAAP concept matching to identify rows with different names but same meaning
   - Example: "Cash from operating activities", "Operating cash flow", "Net cash provided by operations" all map to → OperatingCashFlow
   - Example: "Capital expenditures", "Capex", "Purchase of PP&E" all map to → CapitalExpenditures
5. **Best Fit Selection**: When multiple source rows could map to same concept, pick the one that best fits the standardized concept
6. **Preserve Unmatched Rows**: Add any source rows that weren't matched to required rows at the end of the output (rows 30+)
7. **Missing Data**: Use "-" for periods where data is not available (not "0.00", "NaN", or null)

### Handling Messy Data

- Source tables may have inconsistent column names (Q1'23, 2023-Q1, 1Q23, etc.) - normalize to consistent format
- Line items may appear in different order across periods - you must find and align them correctly
- Some rows may be labeled differently but represent the same concept (use GAAP knowledge)
- Cash flow statements may use direct or indirect method - normalize accordingly
- Some companies show outflows as negative, others as positive with labels - preserve source convention

### Validation & Error Reporting

After the main normalized table, add a `validation_errors` key with a list of issues found:
```json
{
  ...normalized data...,
  "validation_errors": {
    "2022-09-30": [
      "Free Cash Flow does not equal Operating Cash Flow minus Capital Expenditures (3.68B ≠ 6.01B - 2.33B)",
      "Net Change in Cash does not equal sum of Operating + Investing + Financing (3.68B ≠ 6.01B - 2.27B - 2.99B)"
    ],
    "2023-09-30": [
      "Cash Ending does not equal Cash Beginning plus Net Change in Cash"
    ]
  }
}
```

Validate these mathematical relationships:
- Net Change in Cash = Operating Cash Flow + Investing Cash Flow + Financing Cash Flow
- Cash Ending = Cash Beginning + Net Change in Cash
- Free Cash Flow = Operating Cash Flow - Capital Expenditures (if all three present)
- Investing Cash Flow = Capital Expenditures + Business Acquisitions + Investment Changes + Other (if details present)
- Financing Cash Flow = Debt Changes + Equity Changes + Dividends + Other (if details present)

## Your Task

Given the source cash flow statement JSON, produce a normalized output of the said JSON table following all rules above. Remember: **every required row must have actual values from the source - no fabrication, no calculation, only extraction, NO additional context outside the JSON, you MUST only return the JSON.
